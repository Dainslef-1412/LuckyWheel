# Docs

This directory stores supporting project documentation outside the root source-of-truth files.

Root source-of-truth files:

- `SPEC.md`: product behavior, scope, workflows, and acceptance.
- `DATA_DESIGN.md`: configuration object, persistence, share URL, and data compatibility.
- `TECH_DESIGN.md`: architecture, modules, build, deployment constraints.
- `TEST_PLAN.md`: verification commands and acceptance checklist.
- `PROJECT_LAYOUT.md`: local folder contract.
- `AGENTS.md`: concise agent execution entry.

Supporting docs:

- `agent-development-guidelines.md`: detailed agent and development guidance preserved from the previous `CLAUDE.md`.
- `tech/deployment.md`: deployment options and release checklist.
- `delivery/ITERATION_PLAN.md`: current delivery plan and definition of done.

Supporting docs should refine the root files, not override them.
